## Introduction

The **IBM Guardium Data Protection on AWS with DB2 workshop** provides hands-on guided learning experience focused on **IBM Guardium** capabilities with DB2 database integration on AWS. This workshop will help attendees learn how IBM and AWS products and services together can address security and compliance requirements across various industries.

## Business Problem

Customers need to protect their data across their organization with comprehensive monitoring, classification, and policy enforcement. This workshop demonstrates how to implement data protection using IBM Guardium with DB2 databases on AWS infrastructure.

## Target Audience

CISO, Security specialists, Architects, Developers, Database Administrators

## What you will learn

Each lab in the workshop represents a method to **secure data using IBM Guardium with DB2**. By going through each lab, attendees will learn how to implement each method with the help of reference architecture and hands-on exercises.

IBM Guardium Data Protection on AWS with DB2 Workshop is divided into 5 main sections:

* **Section 1**: **Introduction and Architecture** - Understanding IBM Guardium capabilities and workshop architecture

* **Section 2**: **Data Discovery and Vulnerability Assessment** - Learn data classification and vulnerability scanning

* **Section 3**: **DAM and Policy Creation** - Database Activity Monitoring and policy management

* **Section 4**: **Access Controls and Reports** - Implementing access controls and generating compliance reports

* **Section 5**: **Final Considerations** - Workshop wrap-up and next steps

## Workshop Architecture

This workshop deploys two main components:

* **Guardium Data Protection (GDP)** service for comprehensive data security monitoring
* **Scenario Launch Platform (SLP)** to generate realistic database traffic and scenarios

Both services are pre-configured and integrated with DB2 Community Edition to provide a complete learning environment.

## Desired Outcome

This workshop will introduce attendees to the value an integrated IBM-AWS solution brings to data protection use cases using:

  * [IBM Guardium Data Protection](https://www.ibm.com/products/guardium-data-protection)

  * [IBM DB2](https://www.ibm.com/products/db2)

  * [Amazon EC2](https://aws.amazon.com/ec2/)

  * [Amazon VPC](https://aws.amazon.com/vpc/)

  * [AWS CloudFormation](https://aws.amazon.com/cloudformation/)
